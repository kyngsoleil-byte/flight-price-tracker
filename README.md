# Flight Price Tracker

## Project Description
The Flight Price Tracker is a web application that helps users monitor and track flight prices for their desired routes. Users can set alerts for price drops and receive notifications when prices are at their lowest.

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/kyngsoleil-byte/flight-price-tracker.git
   ```
2. Navigate into the project directory:
   ```bash
   cd flight-price-tracker
   ```
3. Install the required dependencies:
   ```bash
   npm install
   ```
4. Set up your environment variables by creating a `.env` file in the root directory and include your API keys.
5. Start the application:
   ```bash
   npm start
   ```
6. Visit `http://localhost:3000` in your web browser to access the application.
